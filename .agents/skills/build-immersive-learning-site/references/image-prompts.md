# Gemini／ChatGPT 場景圖片提示詞

依教學內容，為每個場景各產生一段可直接複製的完整提示詞；用繁體中文，必要時另附英文版本。兩個平台共用自然語言提示；依可用模型與工具調整，但不得保證平台一定能產生有效全景。若使用者要求，也主動使用環境內可用圖片生成工具；若無法產圖，交付完整提示詞供使用者貼至 Gemini 或 ChatGPT。先以一張測試圖片檢視風格，經使用者認可後再批次製作其餘場景。

## 統一規格

提示詞應明確填入：[場景名稱]、[臺灣校園空間及陳設]、[年級]、[時間與光線]、[視覺風格]、[色彩]、[教學情境]、[保留任務入口位置]。跨場景維持同一校園的建築、色調、光線風格與角色設定；每個場景可以描述教學用途，但圖片不要塞入文字、按鈕、浮水印或密集人群，UI 和人物互動由網頁呈現。注意校園安全、文化貼近、避免可辨識真實學生及個資；如果由使用者提供照片，先確認具有使用與公開授權。

## 可複製的球形全景提示詞

「請生成一張用於國小互動教學網站的校園場景圖片。場景：[場景名稱與具體環境]；教學情境：[情境]；視覺風格：[風格]；時間與光線：[光線]；色調：[色彩]。請以站在場景中央、眼睛高度約 [高度] 的單一固定攝影點，呈現完整水平 360 度與垂直 180 度的等距長方投影（equirectangular）全景圖，輸出寬高比 2:1。左右邊緣對齊且能無縫銜接，天空與地面符合該投影；建築與家具在接縫附近連貫。不使用一般廣角單張照片、魚眼圓形投影、多視角拼貼。畫面不要有文字、標誌、介面按鈕、水印或可辨識真人，並在 [位置] 保留清楚空間讓網站覆蓋互動圖示。請維持與其他場景一致的校園設計和氛圍。」

產生後必須檢查實際解析度比例、左右接縫、頂部與底部是否包含合理的天頂與天底，並實際載入球面觀看器從正反方向及上下查看；2:1 不等於全景，平面相機照片也可能是 2:1。影像模型可能忽略投影要求，不能承諾其精準無縫；發現錯誤時具體提出重生或修補建議。無法取得有效全景時，告知限制並使用平面／有限角度備援，不宣稱真實 360 度。不存在真實的視覺檢查能力時，明確說明未驗證。

## 可複製的一般場景提示詞

「請生成國小情境教學互動網站的一張寬幅場景插畫。場景：[場景名稱及臺灣校園細節]；年級：[年級]；故事：[情境]。構圖為 [視角]，有適量視覺層次，色調 [色彩]、風格 [風格]、光線 [光線]；[位置] 保留空白，供網頁加入可點擊任務標記。不要加入文字、浮水印、介面或可辨識真人。延續同系列其他場景的建築設計、色彩和氛圍。」

這是一般場景圖，可用平移或視差營造沉浸感，不能視為或宣稱完整 360 度。實作前讓使用者確認示意與功能範圍。

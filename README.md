# 沉浸式教學網頁製作與發布 Skill

為國中小教學設計互動場景，產生 Gemini／ChatGPT 可使用的場景圖提示詞，製作單一 HTML 沉浸式網站，並依要求協助發布至 GitHub Pages。

## 使用

將本儲存庫以 GitHub Desktop 或 Git 複製到電腦，並在 Antigravity 或 Codex 開啟此儲存庫資料夾。技能位於 `.agents/skills/build-immersive-learning-site/`，兩者皆可從此專案路徑探索技能。私人儲存庫須先以有權限的 GitHub 帳號驗證。

若要在其他專案使用，將完整的 `build-immersive-learning-site` 資料夾（包括 `SKILL.md`、`references` 和其他子資料夾）複製至該專案的 `.agents/skills/`。

範例：
- 在 Codex 中輸入：`$build-immersive-learning-site 幫我製作國小校園情緒探索網站，先產生五個 Gemini 與 ChatGPT 場景圖片提示詞。`
- 在 Antigravity 中輸入：`/build-immersive-learning-site`，並描述主題、學生年級、場景、互動任務及是否需要發布。

技能是指導 AI 助理的工作流程，不是獨立網站。實際功能取決於所使用工具的圖片生成、瀏覽器、GitHub 權限與環境。網站發布需確認實際公開範圍。一般寬幅場景圖不可視為真正 360 度全景。
